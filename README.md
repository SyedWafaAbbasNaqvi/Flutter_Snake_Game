## 🎮 Controls & Features

- **Keyboard**:
  - `W` / `↑`: Move Up
  - `S` / `↓`: Move Down
  - `A` / `←`: Move Left
  - `D` / `→`: Move Right
  - `Space`: Pause / Resume (or Restart if Game Over)
  - `Enter` / `R`: Restart game when Game Over
- **Touch & Mobile**:
  - **Swipe anywhere on the board**: Fluid gesture-based direction control.
  - **On-Screen D-Pad**: Tap buttons for directional control.
- **Features**:
  - **Input Buffering**: Smooth cornering without suicide turns on rapid key inputs.
  - **Accurate Collision Physics**: Prevents false collisions when chasing the snake's tail.
  - **High Score Tracking**: Preserves best score across game sessions.
  - **Victory Detection**: Safely recognizes full board completion without freezing loops.
  - **Responsive Material 3 UI**: Clean dark theme with retro-arcade aesthetic.

## ❓ Troubleshooting

- **"flutter: command not found"**:
  Make sure the Flutter SDK is installed and added to your system's PATH. See [Flutter Installation Guide](https://flutter.dev/docs/get-started/install).
- **"No connected devices found"**:
  Run `flutter run -d chrome` to launch the app inside Google Chrome without needing a mobile emulator.
